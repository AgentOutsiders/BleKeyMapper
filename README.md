# BLE Keycode Mapper

A lightweight, cross-platform C++ daemon designed to intercept raw BLE (Bluetooth Low Energy) notifications and map them to OS-level keystrokes using TOML configuration profiles.

## Status

🚧 **Active Development**

Active development for this project takes place on the **`dev`** branch. The `main` branch is currently kept as a placeholder while the core features are being finalized.

Please switch to the [`dev`](https://github.com/AgentOutsiders/BleKeyMapper/tree/dev) branch to see the source code.
